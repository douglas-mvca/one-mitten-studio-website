# onemittenstudio.com

Pages for the One Mitten Studio website. Plain HTML, no build step.

- `privacy/off-the-sofa.html`: privacy policy for the Off The Sofa app (needed for Google Play, which will
  link to it). Keep it in step with the app: permissions, what's stored, Google Maps, Android backup.
- `assets/`: logo and favicon, copied from the brand repo (one-mitten-studio-brand, `assets/`).

Not hosted yet. Once it is, the policy's address goes in the Play Console (App content → Privacy policy).
